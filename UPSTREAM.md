# Upstream provenance and acknowledgments

BioLync.Pro is a modified fork of [LinkStack](https://github.com/LinkStackOrg/LinkStack). The GitHub fork relationship and commit history preserve the repository lineage. The original project and its contributors are not the BioLync.Pro support or release channel.

The fork adds BioLync.Pro product identity, presentation assets, and native themes, among other repository-visible changes. See the Git history and [branding audit](docs/BIOLYNC-BRANDING-AUDIT.md) for the change record. Preserve copyright, license, and author notices present in source files; this document does not replace those notices or the [AGPL-3.0 license](LICENSE).

For a network deployment, offer the Corresponding Source of the version actually running, including BioLync modifications, to its users. A link to this repository is sufficient only if its published source corresponds to that deployment. Verify the live deployment separately.
